# MyFirstApp — Task 3

An introductory Android application that demonstrates core UI design principles — including custom input fields, gradient buttons, badge tags, and interactive components — built entirely with **Kotlin** and **XML Layouts**.

---

## Key Features

- **Custom UI Components:** Styled EditText fields, gradient buttons, and visual badge tags.
- **User Interaction:** Captures user input and responds to button click events.
- **Edge-to-Edge Display:** Uses `WindowInsets` for a modern full-screen immersive layout.
- **Material Design 3:** Follows Material You guidelines for colors, typography, and spacing.

---

## Tech Stack

| Category | Details |
| :--- | :--- |
| Language | Kotlin |
| UI Layout | Android XML, ConstraintLayout |
| Design | Material Design 3, Custom Vector Assets |

## Getting Started

1. Open **Android Studio**.
2. Click **Open** and select the `MyFirstApp` folder.
3. Let Gradle sync automatically.
4. Press **Run** (`Shift + F10`) to launch on an emulator or physical device.
